## About the Project

This project was created as part of Assignment #4 for the Web Development course.

The main goal of this assignment is to practice creating HTML forms, using HTML5 validation, and styling forms with Bootstrap.

The project contains five tasks, starting with a basic contact form and ending with an advanced registration form.

---

## Tasks

### Task 0 — Simple Contact Form

Created a basic HTML contact form with:

- Full Name
- Email Address
- Message
- Submit button

The form uses HTML form elements such as `<input>`, `<textarea>`, `<label>`, and `<button>`.

---

### Task 1 — HTML5 Validation

Added HTML5 form validation to the contact form.

Validation includes:

- Required fields
- Email type validation
- Minimum and maximum input length

The browser checks the entered data before submitting the form.

---

### Task 2 — Bootstrap Form Styling

Recreated the form using Bootstrap.

Bootstrap classes were used for:

- Form controls
- Labels
- Buttons
- Containers
- Rows and columns
- Responsive layout

Bootstrap Grid was used to make the form responsive on different screen sizes.

---

### Task 3 — Bootstrap Validation Styles

Added Bootstrap validation styles to the form.

The project uses:

- `is-valid`
- `is-invalid`
- `valid-feedback`
- `invalid-feedback`

These classes are used to display success and error messages for form fields.

---

### Task 4 — Registration Form

Created an advanced registration form containing:

- First Name
- Last Name
- Email
- Password
- Confirm Password
- Gender using radio buttons
- Hobbies using checkboxes
- Country using a select dropdown
- Submit button
- Reset button

The registration form uses Bootstrap Grid and HTML5 validation.
